# MINES Crunchbut

크런치벗 0.2.0의 아임웹 상품 상세페이지입니다.

- 이미지: 카페24 `/web/upload/crunchbut/`의 파일. `assets.json`에 파일명과 해시를 기록합니다.
- CSS·JavaScript·폰트: 이 저장소의 `releases/0.2.0/`.
- 상품 본문: `releases/0.2.0/body.html` 또는 동일한 내용의 `body.txt`.
- 미리보기: 루트 `index.html`을 GitHub Pages로 제공합니다.
- 상품 상세설명에는 본문을, 공통 상세페이지에는 배포된 CSS·JavaScript 링크를 넣습니다.
- CSS와 동작은 `data-crunchbut-version="0.2.0"`에만 적용됩니다.

이미지 업로드와 공개 주소 검증 후 본문을 적용합니다. 실제 아임웹 상품 저장은 별도 작업입니다.
